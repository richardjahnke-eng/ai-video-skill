## Objective 1: Code Review & Optimizations

### 1. Graceful Subprocess Error Handling
**The Problem:** Currently, the `run()` function uses `subprocess.run(check=True)`. If `ffmpeg` or `whisper-cli` fails, it raises a raw Python `CalledProcessError`, dumping a stack trace that pollutes the agent's context window.
**The Fix:** Catch the exception and print the standard error cleanly.

```python
# Updated run() function
def run(cmd, cwd=None):
    try:
        return subprocess.run(
            cmd,
            cwd=cwd,
            check=True,
            text=True,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
        )
    except subprocess.CalledProcessError as exc:
        log(f"Command failed: {' '.join(str(c) for c in cmd)}")
        log(f"Error output:\n{exc.stderr}")
        sys.exit(1)
```

### 2. Font Selection Fallback
**The Problem:** You have a great `FONT_CANDIDATES` list, but if a user is running a minimal Linux container (which some cloud agents use), none of these paths might exist, causing PIL to crash during contact sheet generation.
**The Fix:** Implement a fallback to PIL's default font.

```python
# Updated font loading snippet
from PIL import ImageFont

def load_font(font_path, size):
    if font_path and Path(font_path).is_file():
        return ImageFont.truetype(font_path, size)
    for candidate in FONT_CANDIDATES:
        if Path(candidate).is_file():
            return ImageFont.truetype(candidate, size)
    return ImageFont.load_default()
```

### 3. Type Hinting for Agent Visibility
**The Problem:** AI coding assistants (like Cursor) rely heavily on Language Server Protocols (LSP) and type inference. Adding type hints improves the AI's ability to refactor your code later.
**The Fix:** Add standard `typing` hints to your functions.

## Objective 2: Feature Additions

### 1. Whisper Initial Prompt (Vocabulary Injection)
**Why:** Coding videos contain heavy jargon (`React`, `useEffect`, `ffmpeg`, `whisper.cpp`). Standard whisper models often misspell these. Passing an initial prompt massively improves technical accuracy.
**Implementation:**
Add `"initial_prompt": ""` to `DEFAULTS` in `analyze_video.py` and `config.json`. Then, append it to the whisper command:

```python
# In the whisper execution block:
whisper_cmd = [
    "whisper-cli",
    "-m", str(model_path),
    "-f", str(audio_path),
    "-oj" # Output JSON
]
if cfg.get("initial_prompt"):
    whisper_cmd.extend(["--prompt", cfg["initial_prompt"]])
```

### 2. Adaptive Frame Sampling (Max Frames Cap)
**Why:** If an agent attempts to analyze a 2-hour video with `interval_sec: 5`, it will generate 1,440 frames. This creates massive contact sheets and bloats `index.md`, potentially overflowing token limits.
**Implementation:** Add a `max_frames` setting (e.g., `100`). If `duration / interval_sec > max_frames`, dynamically increase the interval.

```python
# Logic to inject after duration is parsed from ffmpeg probe:
if cfg.get("max_frames") and cfg["max_frames"] > 0:
    estimated_frames = duration / cfg["interval_sec"]
    if estimated_frames > cfg["max_frames"]:
        cfg["interval_sec"] = max(1.0, duration / cfg["max_frames"])
        log(f"Adjusted interval to {cfg['interval_sec']:.1f}s to respect max_frames cap.")
```

### 3. Audio-Only Fast Path (Skip Visuals)
**Why:** Sometimes the user just asks "Summarize the transcript of this video." Running `ffmpeg` to extract scenes and pack images is wasted time and compute.
**Implementation:** Add a `--skip-frames` flag and `"extract_frames": true` to `config.json` to let the agent bypass PIL and FFmpeg frame extraction entirely.
